# 历史归档

[gopd-meta-teaching-mvp](gopd-meta-teaching-mvp/) 是早期的元教学原型：OPD warmup后进行独立RL，再用后续收益更新教法选择器。它与现在的G3a是两套实验。

当前G3a只比较固定teacher下的学生训练状态与指导形式，入口是 [experiments/student-state-guidance](../experiments/student-state-guidance/README.md)。不要把这里的旧部署指令当成当前实验的启动入口。

旧原型的源码、配置、许可证和CPU验证记录均保留。旧记录没有证明真实GPU训练通过，本次目录整理也没有替旧原型补做GPU实验。原代码目录说明保留在 [README.legacy.md](README.legacy.md)。
