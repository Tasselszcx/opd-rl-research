# Vendored reasoning-gym

This directory contains the reasoning-gym code and training harness used by the
fixed-teacher student-state study. It is imported as `reasoning_gym`.

The source comes through [StringNLPLAB/opd-rlvr](https://github.com/StringNLPLAB/opd-rlvr)
from [open-thought/reasoning-gym](https://github.com/open-thought/reasoning-gym).
See `LICENSE.reasoning-gym` and `NOTICE.txt` for the retained license and notices.

Use the parent [experiment README](../README.md) for the current setup and data
protocol. This file also supplies the package metadata README required by Hatch.
