# 实验在测什么

**同一个老师，面对刚学了一些和已经学过更多的学生，最有用的指导会不会不同？**

只做K&K真假话逻辑题，固定训练种子42。取普通OPD第30、90步的学生存档，每份各开四组，每组再训练150步：共4×2=8组。30步起点到全局180步，90步起点到全局240步。先完成30步起点四组，再做90步起点四组。

| 组别 | 老师额外看到什么 | 在测什么 |
|---|---|---|
| Baseline | 无额外答案或解法 | 常规OPD对照 |
| 只给答案 | 正确的六人身份分配 | 答案信息是否有帮助 |
| 完整解法 | 正确答案＋64种身份组合的排除证明 | 完整证明是否比答案更有用 |
| 针对错误提示 | 正确答案＋能机械核验的矛盾提示 | 指出具体矛盾是否更有用 |

**Baseline也有老师信号。** 学生先自己答，老师根据原题和学生已写出的前缀，评价下一token的概率。学生通过这些概率学习，不要求老师先拿到标准答案。

八组中，学生始终只看原题；额外材料仅供老师打分。老师权重固定，学生原响应token和mask保留。错误无法机械核验时，回退为只给答案，并记录原因；不删除这条轨迹，也不声称找到了自由推理文本中的首错。

## 固定配置

| 设置 | 数值 |
|---|---|
| 老师 / 学生 | Qwen3-8B / Qwen3-1.7B-Base |
| 学生起点 / 追加更新 | 第30或90步 / 各150步 |
| 训练种子 | 42 |
| 每步题数 / 每题回答数 | 128 / 8 |
| mini batch / 每GPU micro batch | 16 / 1 |
| 学习率 / 回答上限 | 1e-6 / 4096 token |
| 资源 | 共8张GPU，两组并行，每组独占4张 |
| 存档 | 30/90起点保留完整状态；分支途中只记轻量日志；固定终点保存模型 |

同一起点的四组恢复相同模型和优化器状态，使用相同的追加题序。当前范围文件是[kk8-scope.json](../experiments/student-state-guidance/configs/kk8-scope.json)：1条共用准备路线＋8条正式分支。GSM8K、多seed和关键步骤组已退出当前队列。

当前运行的起点来自历史普通OPD存档；新分支统一应用结束符对齐和真实换行修复。历史参考曲线不能直接充当新baseline。公开从头运行会重新准备起点；精确重现当前数值还需要未公开的原始30/90完整存档。

## 怎么测

训练20000题，诊断128题，开发512题，终测1024题，划分已冻结并去重。每25步在开发集做512×8次回答，50/100/150步报告正确率、输出长度和长度上限率。step0是起点成绩，训练reward另列。

每组只评预定终点：每题32次，seed42–73，temperature0.7、top-p0.8、top-k20。报告所有pass@1–32、逐题配对bootstrap和“起点×指导”交互；前后诊断128×16采用独立采样。只有一个训练种子，题目bootstrap不代表换训练种子后的波动。

主判断是：**同一起点下，各指导相对baseline的收益，以及这个收益是否随学生起点改变。** 固定150步终点，不按开发分数挑checkpoint；本轮不进入独立RL或指导生成器阶段。
