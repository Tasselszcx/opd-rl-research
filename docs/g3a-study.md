# 实验在测什么

**同一个老师，面对不同训练阶段的学生，最有用的指导会不会不同？**

只做K&K真假话逻辑题、训练种子42。先从官方Qwen3-1.7B-Base用修复版普通OPD训练150步，保留第30、90步的完整模型、优化器和随机状态。每个起点开四组，各追加150步：共4×2=8组，终点分别为全局180／240。先完成起点30四组，再做起点90四组。

| 组别 | 老师额外看到什么 | 在测什么 |
|---|---|---|
| Baseline | 无额外答案或解法 | 常规OPD对照 |
| 只给答案 | 正确的六人身份分配 | 答案信息是否有帮助 |
| 完整解法 | 正确答案＋64种身份组合的排除证明 | 完整证明是否比答案更有用 |
| 针对错误提示 | 正确答案＋能机械核验的矛盾提示 | 针对本次错误的反馈是否更有用 |

Baseline也有老师信号：学生先答，老师根据原题和学生前缀评价下一token概率。学生始终只看原题，额外信息只给老师；老师权重固定，学生原响应token和mask保留。

错误提示先检查这次完整回答，再让老师给这条回答打分；无法机械核验时回退为只给答案，并记录原因，不删除轨迹，不声称定位了自由推理文本的首错。因此比较的是具体指导方案整体，不能把差异只归因于提示格式。

## 固定配置

| 设置 | 数值 |
|---|---|
| 老师／学生 | Qwen3-8B／Qwen3-1.7B-Base |
| 公共参考 | 修复版从官方Base训练150步，完整保存30／90 |
| 正式分支 | 四种指导×两个起点，各追加150步 |
| 训练种子 | 42 |
| 每步题数／每题回答数 | 128／8 |
| mini batch／每GPU micro batch | 16／1 |
| 学习率／回答上限 | 1e-6／4096 token |
| 资源 | 公共参考先用4张GPU；正式阶段两路并行，各4张 |
| 存档 | 起点完整保存；分支中途只记日志，固定终点只存模型 |

同一起点四组恢复相同模型和优化器，重置到相同追加题序。程序检查参考来源、时间、EOS和真实换行，拒绝外部或旧版参考。范围见[kk8-scope.json](../experiments/student-state-guidance/configs/kk8-scope.json)；GSM8K、其他seed、关键步骤、独立RL和指导生成器不在本轮队列。

## 怎么测

训练20000题、诊断128题、开发512题、终测1024题，划分已冻结。开发每25步做512×8次采样，50／100／150步报告成功率、回答长度与长度上限率。开发采样种子4200显式传入；step0仅是起点成绩，训练reward不当作开发正确率。

正式终测只用固定终点，每题32次，seed42–73，temperature0.7、top-p0.8、top-k20。报告所有pass@1–32、逐题配对bootstrap和“起点×指导”交互；前后诊断128×16独立采样。不挑中途最高分checkpoint。

主判断是各指导相对同起点baseline的收益，及该收益是否随起点改变。30／90还包含优化器历史差异，因此称训练状态效应，不称纯能力因果效应。只有一个训练种子，题目bootstrap不覆盖换训练种子的波动；老师额外计算成本也要报告。
